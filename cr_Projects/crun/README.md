# CookieRunners: Update Nexus (CRUN)
- Modular, isolated from existing CookieRunners/EverLily/Hermes.
- JSON data, graceful fallbacks, adapter for FireClawl.
- Dashboard at crun/web/; start via ./run.sh.
- Skills interfaces ready: crun-update-check, crun-cookie-search, crun-event-tracker, crun-banner-tracker, crun-patch-reader, crun-source-monitor.
- No hardcoded secrets; .env supported.
