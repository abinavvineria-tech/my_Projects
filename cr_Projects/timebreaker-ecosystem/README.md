# TimeBreaker × PureLily Studio

The Ultimate Programming Language & Developer Ecosystem

This repository contains the source code for the TimeBreaker programming language, its compiler/runtime, package manager (tbpm), CLI, PureLily Studio IDE, and associated tools.

## Structure

- `timebreaker/` - Core language implementation (lexer, parser, interpreter, compiler, stdlib)
- `tbpm/` - TimeBreaker Package Manager
- `purelily-studio/` - PureLily Studio IDE (to be implemented)
- `docs/` - Documentation
- `examples/` - Example projects
- `scripts/` - Utility scripts

## Getting Started

See the documentation in `docs/` for building and using the ecosystem.
